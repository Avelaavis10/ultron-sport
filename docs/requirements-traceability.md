# Requirements Traceability

This file maps MVP requirements to the current code foundation. It should be updated whenever a feature changes.

| Requirement | Current implementation | Primary code areas | Test coverage |
| --- | --- | --- | --- |
| Authentication and RBAC foundation | Registration, login, current-user endpoint, BCrypt password hashing, JWT generation/validation, role-protected routes | `AuthController`, `AuthenticationServiceImpl`, `JwtService`, `JwtAuthenticationFilter`, `UltronUserDetailsService`, `SecurityConfig`, `User` | `AuthenticationServiceImplTest`, `AuthSecurityIntegrationTest` |
| UR-02 / FR-02 Athlete profile management | ATHLETE users create one owned profile, view/update `/me`, trigger LevelPlay recalculation, and ADMIN users list profiles | `AthleteProfileController`, `AthleteProfileServiceImpl`, `AthleteProfile`, `CreateAthleteProfileRequest`, `UpdateAthleteProfileRequest` | `AthleteProfileServiceImplTest`, `AthleteProfileRepositoryTest`, `AthleteProfileAchievementIntegrationTest` |

| Organisation/school/club records | Organisation creation, retrieval, update, search/filtering, contact email, location, type, and verification status | `OrganisationController`, `OrganisationServiceImpl`, `Organisation`, `OrganisationRepository` | `OrganisationServiceImplTest`, `CoachOrganisationRelationshipIntegrationTest` |
| Coach-to-athlete organisation verification context | Coach verification requires a CoachProfile and records coach profile, coach organisation, athlete profile, and shared-organisation context; athletes can link profiles to organisations while retaining school/club fallback text | `EvidenceServiceImpl`, `VerificationRequest`, `AthleteProfileServiceImpl`, `CoachProfileServiceImpl`, `OrganisationServiceImpl`, `VerificationContextResponse` | `EvidenceServiceImplTest`, `EvidenceWorkflowIntegrationTest`, `CoachOrganisationRelationshipIntegrationTest` |

| UR-04 / FR-04 Evidence verification | Athletes submit evidence to PENDING_VERIFICATION; coaches with CoachProfile verify or reject with reason and recorded organisation context; admins flag or archive evidence | `EvidenceController`, `EvidenceServiceImpl`, `VerificationRequest`, `VerificationRequestRepository` | `EvidenceServiceImplTest`, `EvidenceWorkflowIntegrationTest`, `VerificationRequestServiceImplTest` |

| UR-07 / FR-08 Recommendations readiness | Discovery returns LevelPlay summaries and verified evidence signals without implementing recommendation AI yet | `DiscoveryServiceImpl`, `LevelPlayScoreSummaryResponse`, `AthleteDiscoveryCardResponse` | `DiscoveryServiceImplTest`, `DiscoveryIntegrationTest`, `LevelPlayIntegrationTest` |

| Athlete search and filtering | Search foundation supports sport, location, and position filters | `AthleteProfileController`, `AthleteProfileServiceImpl` | `AthleteProfileServiceImplTest` |

| UR-12 Compliance & ethics | Admin/moderation actions are recorded as append-only audit logs with typed action/target metadata and no exposed sensitive auth fields | `AdminActionLog`, `AdminActionType`, `AdminTargetType`, `AdminActionLogResponse` | `AdminActionLogServiceImplTest`, `AdminModerationIntegrationTest` |
| Auditability of evidence moderation | Evidence flag/archive actions create durable AdminActionLog records | `EvidenceServiceImpl`, `AdminActionLogServiceImpl` | `EvidenceServiceImplTest`, `AdminModerationIntegrationTest` |

| Explainability/fairness non-functional requirement | Score explanation exposes the inputs and confirms popularity, fan votes, views, likes, paid boosts, and AI scoring are excluded | `LevelPlayScoreExplanationResponse`, `LevelPlayController` | `LevelPlayScoreServiceImplTest`, `LevelPlayIntegrationTest` |
| Data quality non-functional requirement | Profile and achievement DTOs validate required fields, future dates, size limits, duplicate profile prevention, and ownership boundaries | `CreateAthleteProfileRequest`, `UpdateAthleteProfileRequest`, `CreateAchievementRequest`, `UpdateAchievementRequest`, `AthleteProfileServiceImpl`, `AchievementServiceImpl` | `AthleteProfileServiceImplTest`, `AchievementServiceImplTest`, `AthleteProfileAchievementIntegrationTest` |
| LevelPlay integration with evidence workflow | Coach verification automatically recalculates the athlete score | `EvidenceServiceImpl`, `LevelPlayScoreServiceImpl`, `VerificationRequestRepository` | `EvidenceServiceImplTest`, `LevelPlayIntegrationTest` |
